# NeuroHub — единый чат для ИИ-моделей

Статический сайт для GitHub Pages. Основной вариант для бесплатного использования — OpenRouter Free Models Router (`openrouter/free`), который выбирает доступную бесплатную модель. Также предусмотрены прямые подключения к DeepSeek API, OpenAI API (ChatGPT), Anthropic Claude API, YandexGPT через Yandex Cloud и произвольному OpenAI-совместимому API.

## Что может быть бесплатным

- **OpenRouter Free**: доступ к моделям с нулевой стоимостью, но с низкими лимитами и переменной доступностью. Требуется собственный ключ OpenRouter.
- **DeepSeek**: веб-чат может быть бесплатным, но DeepSeek API обычно оплачивается отдельно.
- **ChatGPT / OpenAI API**: подписка ChatGPT не включает автоматически бесплатный API.
- **Claude API**: API обычно требует биллинга/кредитов; подписка Claude.ai не является API-ключом.
- **YandexGPT / Алиса**: подключение через Yandex Cloud API; бесплатные лимиты/пробные средства зависят от условий аккаунта. Это не прямое подключение к потребительскому приложению Алиса.

Актуальный каталог бесплатных моделей OpenRouter: https://openrouter.ai/models?pricing=free

## Публикация на GitHub Pages

1. Создайте публичный репозиторий, например `neurohub`.
2. Загрузите в корень репозитория `index.html`, `style.css`, `app.js`, `README.md`.
3. Откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем сохраните.
5. Дождитесь публикации и откройте URL, который GitHub покажет в Pages.

## Подключение

Откройте сайт → **Настройки API** → добавьте ключ нужного провайдера → сохраните → выберите модель в нижней панели.

- OpenRouter: https://openrouter.ai/keys
- DeepSeek: https://platform.deepseek.com/
- OpenAI API: https://platform.openai.com/api-keys
- Anthropic Claude: https://console.anthropic.com/
- Yandex Cloud: https://console.yandex.cloud/

Для YandexGPT нужны API key сервисного аккаунта и Folder ID. Используйте актуальную документацию Yandex Cloud при настройке прав и биллинга.

## Безопасность

Это клиентское приложение без backend. API-ключи хранятся в `localStorage` браузера и используются напрямую из браузера. Не вводите ключи на чужих устройствах и не помещайте их в GitHub. Не используйте один личный ключ как общий для всех посетителей: это может привести к расходам и исчерпанию лимитов. Для общего централизованного доступа нужен серверный backend с авторизацией, ограничением запросов и защищённым хранением ключей.

## Ограничения

- Бесплатные модели OpenRouter имеют лимиты и могут быть временно недоступны.
- Прямые API DeepSeek, OpenAI и Claude могут быть платными.
- Браузерный доступ к API зависит от CORS и правил провайдера.
- YandexGPT использует формат Yandex Cloud API, а не API потребительской Алисы.
- История и настройки хранятся только в текущем браузере; аккаунтов и синхронизации нет.
