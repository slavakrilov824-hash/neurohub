# NeuroHub — единый чат для ИИ-моделей

Статический сайт для GitHub Pages. Поддерживает Google Gemini API, Anthropic Claude API, OpenRouter и произвольный OpenAI-совместимый endpoint.

## Публикация на GitHub Pages

1. Создайте новый **публичный** репозиторий на GitHub, например `neurohub`.
2. Загрузите в корень репозитория `index.html`, `style.css`, `app.js`, `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
5. Дождитесь публикации — GitHub покажет URL сайта в разделе Pages.

## Подключение моделей

Откройте сайт → «Подключить модели» / «Настройки API», вставьте ключ провайдера и сохраните. Выберите модель в нижней панели чата.

- Gemini: https://aistudio.google.com/apikey
- OpenRouter: https://openrouter.ai/keys — каталог моделей: https://openrouter.ai/models
- Claude: https://console.anthropic.com/ — доступ к API может требовать биллинга/кредитов; подписка Claude.ai не является API-ключом.

У бесплатных моделей и тарифов есть ограничения, они могут меняться. Наличие модели в списке не гарантирует, что конкретный аккаунт имеет к ней доступ.

## Важная безопасность

Это клиентское приложение без собственного сервера. API-ключи сохраняются в `localStorage` браузера и используются напрямую для вызовов провайдеров. Не вводите ключи на чужих или общедоступных устройствах. Не размещайте свои ключи в исходниках, GitHub, скриншотах или общедоступной конфигурации. Если сайт будет доступен другим людям, каждый посетитель должен вводить собственный ключ; иначе ваши расходы и лимиты могут использовать посторонние. Для общего публичного доступа с централизованными ключами понадобится серверный backend с защитой ключей, авторизацией и ограничением запросов.

## Ограничения текущей версии

- Диалоги и настройки хранятся локально в текущем браузере; аккаунтов и синхронизации между устройствами нет.
- Для Claude используется режим прямого браузерного доступа Anthropic, который провайдер может ограничивать или менять.
- Произвольный endpoint должен разрешать браузерные CORS-запросы и поддерживать формат OpenAI Chat Completions.
- GitHub Pages размещает статические файлы и не запускает серверный код.

## Разработка

Откройте `index.html` в браузере или используйте локальный статический сервер. Проект не требует сборки и зависимостей.
