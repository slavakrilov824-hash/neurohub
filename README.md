# Хор — много нейросетей в одном чате

Статический сайт (без сборки, чистый JavaScript) для GitHub Pages. Чат с потоковыми ответами, историей, поиском,
редактированием сообщений и переключением между провайдерами. **Ключи вводит пользователь, они хранятся только в его браузере.**

## Провайдеры

| Провайдер | Доступ | Ключ | Заметки |
|---|---|---|---|
| OpenRouter | бесплатные модели `:free` | да | 20 запросов/мин, 50/день (1000/день после разовых $10 кредитов) |
| Groq | бесплатный тариф | да | лимиты на каждую модель, карта не нужна |
| Google Gemini | бесплатный тариф для части моделей | да | ключ из AI Studio; Pro и медиамодели могут быть платными |
| Ollama | локально | нет | нужен `OLLAMA_ORIGINS` |
| Свой endpoint | любой OpenAI-совместимый | по сервису | Mistral, Cerebras, LM Studio и т. п. |
| DeepSeek, Qwen | платно/пробная квота | да | CORS из браузера не проверен |
| OpenAI, Anthropic | платно | да | подписка ChatGPT/Claude ≠ API |

Условия меняются; перед использованием сверяйтесь со страницей провайдера (данные собраны 13.10.2026). Списки моделей
загружаются из API провайдеров кнопкой ⟳, поэтому идентификаторы не устаревают; можно ввести ID вручную.

## Локальный запуск
```bash
python3 -m http.server 8080   # или: npx serve .
# открыть http://localhost:8080
node tests/run.mjs            # тесты на мок-ответах (Node 18+)
```
ES-модули не работают с `file://` — нужен любой статический сервер.

## Публикация на GitHub Pages
1. Создайте репозиторий и отправьте файлы в ветку `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` прогонит тесты и опубликует сайт на `https://<логин>.github.io/<репозиторий>/`.

## Ключи и безопасность
- Ключи вводятся в «Настройки», по умолчанию живут в `sessionStorage` (до закрытия вкладки); галочка «Запомнить» — `localStorage`.
- Ключ уходит только на API выбранного провайдера. Секретов в коде нет; `.gitignore` исключает `.env` и `*.key`.
- Страница ограничена CSP; ответы моделей рендерятся с полным экранированием HTML.
- Статический сайт не может защитить общий ключ. Для общего бесплатного доступа нужен backend-прокси
  (Cloudflare Workers / Vercel / Deno Deploy) с ключом в секретах, авторизацией и ограничением запросов — в проекте его **нет**.
- Для платных провайдеров используйте ключ с лимитом расходов.

## Добавление провайдера
В `js/providers.js` добавьте объект в `PROVIDERS` и id в `ORDER`. Для OpenAI-совместимого API:
```js
mistral: { id:'mistral', name:'Mistral', access:'freemium', accessLabel:'Бесплатный тариф', tagline:'…',
  needsKey:true, keyUrl:'https://console.mistral.ai/', fallback:[], limits:'…', howto:['…'], cors:'…',
  ...openaiCompat({ baseUrl:'https://api.mistral.ai/v1' }) }
```
Свой протокол: реализуйте `listModels(ctx)` и `async *stream(ctx)` (отдаёт куски текста), ошибки — через `ApiError`.
Ключ `needsKey`, а также ключ в «Настройках» подхватятся автоматически для провайдеров с `needsKey:true`.

## Частые ошибки
- **«Ключ не принят» (401/403)** — неверный/отозванный ключ или нет доступа к модели.
- **429** — исчерпан лимит; подождите, смените модель или провайдера.
- **402 у OpenRouter** — отрицательный баланс, даже `:free` не работает.
- **404** — модель убрана; обновите список ⟳.
- **«Не удалось связаться»** — сеть, VPN/блокировщик или CORS (у DeepSeek/Qwen не проверено).
- **Ollama не отвечает** — запущена ли служба, задан ли `OLLAMA_ORIGINS`; Safari блокирует http://localhost с https-страниц.

## Горячие клавиши
Enter — отправить · Shift+Enter — новая строка · Esc — остановить · Ctrl/Cmd+K — поиск · Ctrl/Cmd+Shift+O — новый чат.
